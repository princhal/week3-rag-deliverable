About this experiment

Three chunking strategies were applied to a 16-page PDF and evaluated against 10 semantic queries. Embeddings were generated using all-MiniLM-L6-v2 (384 dimensions, local CPU inference). Vector similarity search runs on Supabase pgvector with an HNSW index (m=16, ef_construction=64). Retrieval quality is measured by HR@3 (hit-rate at 3) as the primary metric.
